FitLife PWA - upload these files (all in the SAME folder, no sub-folders) to a GitHub repository:
index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png, icon-maskable-512.png, apple-touch-icon.png

Then on GitHub: Settings > Pages > Source: "Deploy from a branch" > Branch: main, folder: / (root) > Save.
After about a minute your app is at https://YOUR-USERNAME.github.io/REPOSITORY-NAME/

Android (Chrome): open the link > tap Install (or menu > Install app).
iPhone (Safari): open the link > Share > Add to Home Screen.
